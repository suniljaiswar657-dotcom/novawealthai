# NOVAWEALTH AI

Next-generation AI-powered savings and wealth management platform.

## MVP preview

A mobile-first fintech product prototype with:
- Savings overview dashboard
- Savings goals and progress tracking
- Daily savings planner
- Demo top-up and demo save actions
- Recent activity history
- Smart Coach preview
- Local browser persistence

## Important scope note

This repository currently contains a **simulation-only MVP**. It does not connect to a bank, UPI, payment gateway, digital-gold provider, or investment account. No real money is collected, transferred, invested, or stored. The Smart Coach is currently a rules-based preview, not a connected AI financial adviser.

Real-money features require appropriate regulated/authorized partners, security review, legal review, and applicable compliance approvals.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
